# 🏀 Basketball Scoreboard

A clean, interactive web-based basketball scoreboard built to track live game scores and periods in real time.

 [View Live Demo](https://graceadegboye20-hue.github.io/Basketball-scoreboard-4-js-new/)

 Features
- Live Score Tracking: Increment Home and Guest scores using +1, +2, and +3 point buttons.
- Period Controls: Track and update game quarters/periods seamlessly.
- Game Reset: Quickly reset scores and periods to start a fresh match.
- Responsive Design: Clean, readable scoreboard UI styled for desktop and mobile screens.

 Built With
- HTML5 – Semantic structure
- CSS3 – Custom styling and layout
- JavaScript (ES6) – DOM manipulation and scoring/period logic

 What I Learned
Building this project sharpened my ability to manage application state in vanilla JavaScript, handle user events cleanly, and translate UI designs into responsive layouts.
